# FloodLab 洪涝分析与制图工作台

本地课程产品原型。默认打开瓦伦西亚 Horta Sud 的真实分析记录，支持继续提交自然语言要求，
由语言模型逐步调用 QGIS 工具，生成统计图层、专题图和可编辑工程。

## 启动

在项目根目录：

```sh
npm --prefix workbench ci --ignore-scripts
.venv/bin/python workbench/server.py --ask-key
```

打开 `http://127.0.0.1:8765`。密钥通过隐藏输入读取，仅保留在服务进程内存，
不写入项目、浏览器本地存储或实验记录。不使用在线推理时可省略 `--ask-key`；
历史地图、任务轨迹和下载仍可查看。也可在界面的模型连接窗口输入密钥。

运行需要已有 QGIS 环境 `.tools/qgis`，环境准备见项目 README。服务只监听本机回环地址，
默认只允许同源浏览器请求。端口占用时使用 `--port 8766`。

## 产品中的真实操作

- 查看实际灾前 Sentinel-2 RGB 影像、EMS 洪涝轮廓和历史 OSM 道路。
- 比较任务的历史版本与当前版本，选择暴露长度或暴露率进行浏览。
- 点击排名网格定位，读取总长度、暴露长度、暴露率。
- 输入新的分析要求，在后台实际执行工具调用，保留每次参数与返回。
- 获取 Agent 实际导出的 PDF、PNG、QGIS 工程和 GeoPackage。
- 停止操作会请求在当前模型调用结束后停止；不会伪装成瞬时取消远程请求。

默认示例是两个连续请求：全部道路、1 km 网格、按长度排名；
随后筛选四类主干道路、改为 2 km 网格、按暴露率排名。数值用独立 Shapely
程序核对。两套计算均使用 GEOS，不能视为独立测绘真值。

## 实现边界

当前产品固定为单一研究区，读取项目已经冻结的数据，并不支持任意地区的数据自动获取。
新任务使用供应商列出的 `gpt-6.1-sol` 接口标识，不能据此独立确认供应商内部模型身份。
界面中的浏览指标切换仅改变显示；输入新的道路类别、网格尺度等要求才会实际重新分析。
若图层没有百分数字段，界面使用其已计算的 total_m 与 exposed_m 显示暴露百分比，
零分母仍为空；下载的原始图层及其 0–1 比例字段不会被修改。
已有核验标记只属于明确匹配的结果，不自动授予后续 Agent 输出。

历史工作空间不被直接修改。继续分析时创建新的运行目录，复用不可变输入和旧成果，
记录后续新图层以及依赖失效状态。下载 QGIS 工程时还需保留它引用的项目数据文件；
单独一个 QGZ 不是全部数据的自包含包。

## 检查

`qa/checks.json` 记录真实浏览器操作：版本切换、指标切换、网格定位、图层切换、
PDF 下载、地图预览、手机布局和真实任务提交。`qa/*.png` 是页面截图，不是设计效果图。
`qa.mjs` 使用本机 Codex 捆绑的 Playwright；其他机器可安装 Playwright 并调整模块位置。
模型运行记录位于 `event/runs/workbench_*/agent-run.json`，
工具轨迹位于同目录 `tools.jsonl`。数值核验程序为 `event/verify_gis.py`。
