# 洪涝工作区追问回归

从已发布的 Kastelli 分析复制数据和历史到临时工作区，以供应商别名 `gpt-6.2-sol` 通过 Pi / Responses 连续运行三轮。修改前后各执行一次，问题、顺序和初始工作区一致，原始工程不受影响。

| 追问 | 修复前 | 修复后 |
|---|---|---|
| 7.2% 是整个岛的比例吗？不要重算。 | 正确解释为单格分母，显示原图 | 正确解释，显示原图 |
| 换到保亭，不联网、不下载、不计算，只列道路分析缺什么。 | 正确列出所缺资料，但回答下面仍挂有克里特岛地图 | 列出所缺资料，不挂旧图 |
| 回到刚才的 Kastelli 地图，不要重新计算。 | 返回旧图，但文字错误地说不能直接预览 | 回复提示可点开已有地图，返回正确成果 |

三轮均没有调用检索、下载或空间计算工具；仍需要模型接口联网生成回复。“不联网”在此测试中指不联网查数据，不代表支持离线推理。结构化检查仅核对任务状态、工具记录和对应产品；回答语义另行阅读。这是一组开发回归，不是总体准确率评估。

本地记录：`desktop/qa/followups-before.json` 与 `desktop/qa/followups-after.json`。复跑：`.venv/bin/python desktop/check_followups.py after`。另用受控测试核对同一产品不同网格版本的选择、无效地图引用和空新闻结果与已完成空间统计并存的情形。
