本轮找到的新增问题包括：过时的 UI 测试可能指到错误版本；EMS 目录数据被误当作新闻引用会触发缺键；缓存命中会刷新原下载时间，未登记的旧文件可能与新散列不一致；跨事件地图只画洪涝轮廓，无法定位排名。候选版补了证据来源区分、缓存一致性和地图标注。新 PDF 以可搜索文字显示前五网格，与 GeoJSON 排名一致。

实际重跑取得 Kastelli 的 88 个观测多边形和 20 个非零相交网格。另用 Shapely 从下载源文件重新做等积投影及合并，面积为 0.24126592903172 平方公里，与 QGIS 结果的绝对差小于 7e−13 平方公里；两种实现均调用 GEOS，这不是观测精度验证。新 QGIS 工程重开时两层均有效，检查了实际导出的地图版面。

本机的检查明细与新版地图在 `delivery-qa/regression-0.6.1/`。0.6.1 作为独立 Release，保留原 0.6.0 文件，两个安装包的散列随新版发布。

## 复跑

按 [复现说明](REPRODUCTION.md) 准备 QGIS、Python、浏览器及输入。在项目根目录运行：

```sh
npm --prefix desktop ci
.venv/bin/python desktop/acceptance.py --out /tmp/floodlab-check
.venv/bin/python desktop/acceptance.py --live --out /tmp/floodlab-live-check
```

`--out` 必须指向尚不存在的目录。默认测试不调用付费模型；`--live` 会访问模型接口与在线事件数据，API Key 通过隐藏输入或环境变量提供。各项的退出码、日志、报告和截图留在指定目录。可用 `--only live-project` 单独重跑下载制图。实际模型与实时检索会随接口和数据变化，不能用本次通过次数估计普遍成功率。

桌面检查在对应平台运行 `desktop/smoke.mjs`，设置 `FLOODLAB_APP` 为安装包中实际可执行文件，并为 `FLOODLAB_USER_DATA` 选新的本地目录。Windows 需要在 Windows x64 主机上执行，不能用 macOS 上的打包验证替代。
